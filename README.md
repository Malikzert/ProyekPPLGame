## 🏃‍♂️ Tentang ECO RUNNER

**Eco Runner** adalah proyek game edukasi bertema lingkungan yang dikembangkan sebagai bagian dari tugas mata kuliah **Pengembangan Perangkat Lunak (PPL)**. Game ini menantang pemain untuk berlari sambil mengumpulkan sampah atau menghindari rintangan demi menjaga kelestarian lingkungan digital.

Proyek ini merupakan hasil **kolaborasi tim**, yang menekankan pada manajemen kode yang bersih, pembagian tugas (task division), dan alur kerja Git yang terintegrasi.

## ✨ Fitur Utama

- **Endless/Level Runner**: Mekanik lari yang responsif dan menantang.
- **Eco-Mission**: Sistem skor berdasarkan item ramah lingkungan yang dikumpulkan.
- **Progressive Difficulty**: Tingkat kesulitan yang meningkat seiring jauhnya jarak tempuh.
- **Collaborative Development**: Struktur scene dan script yang modular agar mudah dikembangkan bersama tim.

## 🚀 Cara Menjalankan Proyek

1. **Clone repository**:
   ```bash
   git clone [https://github.com/Malikzert/ProyekPPLGame.git](https://github.com/Malikzert/ProyekPPLGame.git)

```
```
2. **Download Godot**:
Pastikan Anda menggunakan **Godot Engine 4.x** (sesuaikan dengan versi yang tim gunakan).
3. **Import Project**:
* Buka Godot Engine.
* Pilih **Import**.
* Arahkan ke folder hasil clone dan pilih file `project.godot`.


4. **Play**:
Tekan `F5` untuk menjalankan game dari scene utama.
```
